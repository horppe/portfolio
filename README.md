# Samson Oluokun Portfolio

A personal portfolio for Samson Oluokun, a full-stack software engineer based in Lagos, Nigeria. The site presents selected product work, professional experience, technical skills, and an interactive gallery of 3D model experiments.

## Site Content

- Hero introduction and resume link
- About section focused on product engineering and 3D graphics programming
- Selected hobby projects and work projects
- Professional experience timeline
- Technology stack overview
- Contact form and social links
- Interactive 3D model gallery powered by `model-viewer`

## Featured Work

### Hobby Projects

- **3D Model Gallery**: Interactive experiments in form, material, and 3D graphics programming.
- **Portfolio Template**: A focused portfolio system for developers.
- **Flexbox Music App**: A responsive music app interface built with HTML, CSS, and Flexbox.
- **Security Risk Pipeline**: A GitHub Actions pipeline for surfacing security risk before production.

### Professional Work

- **Cardic**: Digital banking across web and mobile.
- **MyCashierLife**: Commerce and cashier tools for businesses.
- **Omnibiz Retail**: Ecommerce tools for retailers.
- **Lit by FirstBank**: A mobile banking experience.
- **Stanbic IBTC Mobile**: A full-service mobile banking application.
